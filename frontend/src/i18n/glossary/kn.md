# Kannada word list for SchoolGiant (use these every time)

Style: formal, plain standard Kannada as Karnataka schools and government offices write it — short sentences, no
"Kanglish". Buttons and actions use the polite imperative (ಉಳಿಸಿ, ರದ್ದುಮಾಡಿ). Address the user respectfully (ನೀವು).
Keep in English/Latin letters: SchoolGiant, UPI, SMS, WhatsApp, OTP, QR, PDF, Excel, CSV, Razorpay, Jitsi, Zoom, Google
Meet, Teams, CBSE, ICSE, NAAC, NIRF, AISHE, UDISE, APAAR, PEN, GSTIN, PAN, TC (or ವರ್ಗಾವಣೆ ಪ್ರಮಾಣಪತ್ರ), email
addresses, codes, units like "mm", "%", "₹".
